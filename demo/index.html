Qual LLM escreveu este texto?

Cole um texto em inglês, de preferência entre 50 e 300 palavras. O modelo compara o estilo com o de 18 LLMs (GPT, Gemini, Claude, Qwen, GLM e Kimi) e mostra as marcas que mais pesaram. Tudo roda no seu navegador: o texto não sai daqui.

      Como funciona

      Quatro visões do texto viram atributos TF-IDF: n-gramas de caracteres, palavras, a forma das palavras (cada palavra vira X ou x) e o esqueleto de palavras funcionais (o conteúdo vira CONTENT). Uma regressão logística decide entre os 18 modelos. Os pesos foram exportados do Python para int8, e um teste garante que o JavaScript dá as mesmas probabilidades.

      Esta é a versão compacta, com 30 mil termos por visão, para carregar rápido. A solução completa, um blend treinado com o Open Pool, fez 0,413 na validação por prompt e 0,415 no placar público.
